## 用例设计思路（写给自己看）

1. 先按**输入项**拆：每个输入框有哪些"合法"和"不合法"的取值
2. 再按**业务流程**拆：正常流程走一遍，异常分支各走一遍
3. 最后按**边界**补：最短、最长、刚好、差一位
4. 写完自查：这条用例如果执行失败，能不能定位到具体原因？
