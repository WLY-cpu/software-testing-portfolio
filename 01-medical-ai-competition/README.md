# 2026 AI 大赛 · 赛道八：胸部 X 光智能诊断系统

> 这个系统从数据到报告由我独立完成：五道关卡、34 个 Python 文件，含训练、推理、GUI 和 HTTP 服务。
> 代码见 [`src/`](src/)，完整说明见 [`src/README.md`](src/README.md)。

## 系统做什么

输入一张胸片，依次经过五道关卡，输出结构化报告：

1. **真实性检测** —— 是不是真实人体胸片（排除翻拍、合成、非人体）
2. **规范性审核** —— 重复片去重、拼接篡改检测（ELA + 拼接 CNN）
3. **病灶检测** —— YOLOv8m 找出肿块、结节、气胸、积液等 7 类病灶
4. **分期推测** —— 对病灶区域裁剪后用 ResNet50 估分期
5. **可解释与审计** —— GradCAM 热力图 + 关键点测量 + 医保审核风险提示

## 我具体做了什么（全部）

| 模块 | 我的工作 |
|---|---|
| 真实性检测 | 设计并实现**双分支**结构：空域 ResNet50 + 频域 FFT-ResNet18，特征拼接（2048+512）后 3 分类；写了训练、AUC 评估、阈值搜索 |
| 规范性审核 | 感知哈希去重（`hash_db.pkl`）+ 拼接 CNN + ELA 误差分析，封装成 `NormalityGate` 门控 |

| 可解释 / 审计 | GradCAM 挂在分期模型上出热力图；关键点检测与测量标注；医保审核风险规则 |
| 工程化 | `pipeline.py` 串联五关卡；`competition_output.py` 按赛事规范输出 JSON；`inference_server.py` HTTP 服务；`gui.py` Tkinter 界面；`path_utils.py` 统一路径与 `sys.path` |

## 这次最大的技术收获（也是我选测试的原因）

训练时模型在**某一类影像**上识别率怎么都上不去。队友主张加大模型，我坚持先排查数据——在真实项目里，“某一类怎么调都不准”最常见的原因是标注错误或数据分布不均，而不是模型容量不够。

把训练集逐张过一遍后，果然查出：**标注框偏移**、有几张**类别标错**。清洗完这批数据，同一个模型的识别率明显回升。

结论：**很多看起来像“算法不行”的问题，其实是“数据不干净”。** 而找出它靠的是耐心和逐条核对的习惯——这正是测试岗位每天在做的事。
