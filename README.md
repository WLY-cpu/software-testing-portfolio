## 背景：我为什么做这件事

参加 2026 AI 大赛（赛道八）时，我独立开发了一套胸片智能诊断系统：五道关卡，从真伪判别（空域 ResNet50 + 频域 FFT-ResNet18 双分支）、拼接篡改检测（ELA + CNN）、YOLOv8 病灶检测、ResNet 分期，一直做到 GradCAM 热力图和结构化报告。

训练时模型在某一类影像上识别率一直上不去。队友建议加大模型，我先去查数据——最后查出**标注框偏移**和几张**类别标错**。清洗之后，同一个模型的识别率明显回升。

所以我的判断是：

> **写代码正在变便宜，确认代码是对的，正在变贵。**

AI 不会自己认错，它的输出必须被人验证。这就是我选择软件测试的原因，也是这个仓库存在的理由。
